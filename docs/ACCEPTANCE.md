## 功能

- [x] 首页显示六个工具卡片和内置/自定义模板，页面可进入并返回。
- [x] 幸运转盘先确定结果再动画，指针与结果一致；运行时输入与操作禁用。
- [x] 抽签不重复模式维护剩余池，抽空提示并可重新开始；重复模式保留候选池。

- [x] 历史可查看详情、再次使用、长按删除、确认后清空；上限 200 条。
- [x] 设置包含振动、音效、主题、自动保存和三种相互隔离的数据清理。
- [x] 隐私页明确本地保存、无网络、无采集与卸载删除。

## 稳定性与适配

- [x] 所有动画在运行期间锁定重复操作。
- [x] 切后台会取消未完成动画，不提交预计算结果。
- [x] 设置、模板和历史通过 Preferences 在重启后保持。

- [x] ArkUI 页面由 `NavDestination` 承载，无 WebView 或跨端层。
